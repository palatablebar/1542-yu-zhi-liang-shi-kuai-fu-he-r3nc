# 预制梁试块复核数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `cure_min` | 有效保温 | min | 100–600 |
| `chamber_c` | 蒸养峰温 | ℃ | 32–74 |
| `binder_kg` | 胶凝料用量 | kg/m³ | 235–410 |
| `water_pct` | 水胶质量比 | % | 30–57 |
| `probe_gap` | 两探头温差 | ℃ | 1–22 |
| `age_hours` | 脱模前龄期 | h | 9–32 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。标签 0 为已核实正常，1 为需要复核的实绩。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 蒸养抄表 | `soak_seconds` | 保温秒数 | 60 | 0 |
| 蒸养抄表 | `peak_deci_c` | 峰温十分度 | 10 | 0 |
| 待压试块 | `binder_per_batch` | 每立方胶材克数 | 1000 | 0 |
| 待压试块 | `water_permille` | 水胶质量千分数 | 10 | 0 |
| 脱模记录 | `dual_probe_deci_c` | 双探头温差十分度 | 10 | 0 |
| 脱模记录 | `demold_age_minutes` | 拟脱模龄期分钟 | 60 | 0 |

示例见 `sample_data/beam_register_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[1,40)`、校准 `[42,62)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `heat_degree` | 有效温时积 | `cure_min * max(0,chamber_c - 15) / 600` |
| `water_load` | 胶材水负荷 | `water_pct / binder_kg` |
| `gap_rate` | 单位龄期梯度 | `probe_gap / age_hours` |
| `bound_water` | 等效胶材量 | `binder_kg * (1-water_pct/100)` |
| `maturity_age` | 龄期温时代理 | `age_hours * chamber_c / 100` |

### L2 试块风险分类

用带二范数惩罚的二项对数似然，牛顿步配合回溯。以分支形式计算 sigmoid，避免指数溢出。

本工作台的独立样本校准方式为试块校准斜率和偏置。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较分区累积分布差。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 安排试块复压

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `HEAT_GRADIENT` | `probe_gap >= 17 and chamber_c > 59` | 热梯度偏高，暂停脱模 |
| 2 | `SOFT_MIX` | `water_pct >= 47 and age_hours <= 18` | 湿配比且龄期不足 |
| 3 | `WITNESS_PRESS` | `cure_min < 240 and binder_kg < 285` | 要求见证复压 |

第一条为暂停规则。其余命中与模型阈值 `0.49` 共同决定是否列入候选。单据所需工位数按 `1 + int(probe_gap >= 12)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 试块见证排组

由蒸养温时积、龄期和水胶比估算所需试块。梯度异常时冻结试压组号并保留待见证量。试压组号由本班占用顺序产生。 在派发环节展开现场安排，或从关联单据回查实际读数。
